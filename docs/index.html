Run on Real Data (CLI & Full Audit Trail)

This page runs a live browser demo on the 300-student sample dataset. For real cohorts (with Excel .xlsx support, schedule eligibility constraints, and SHA-256 tamper verification), clone the repository and run the Python CLI locally: 

git clone https://github.com/mickaeltemporao/decaIV.git
cd decaIV
uv sync
uv run deca solve

You can also run uv run deca validate before solving and uv run deca explain outputs/run_<stamp>_<id> <STUDENT_ID> to audit any individual placement.
